# Versioned diagnostics lane

## Change

Kernel startup, attach, and display diagnostics now include a source-derived
`<target>/<commit>` build version. The version is generated by
`scripts/build-metadata.sh` from the selected target and the current Git
revision. `scripts/ccxx.sh` generates the header consumed by the IOKit kernel
sources; `scripts/link.sh` records the same value at
`Contents/Resources/build-version.txt` and prints it in link output.

The display diagnostics no longer print the scanout physical address. No new
address, pointer, firmware path, or other sensitive value is exposed by the
versioned messages.

## Target safety

Metadata generation accepts only `sequoia` or `tahoe`. Tahoe generation runs
`target-preflight.sh` and remains fail-closed while
`SOURCE.lock:tahoe_target_validated=no`. This preserves the existing Tahoe
ABI gate and does not add a RecoveryOS or runtime opt-out.
